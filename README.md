# pandas-practice

Jupyter Notebook でデータを探索するときに必要な**簡単な pandas 操作を、何も見ずに反射的に書けるようになる**ための問題集です。

ゴールは「初めて見るCSVを開き、データの構造・欠損・型・分布・カテゴリ・簡単なグループ差を**数分で自力で確認できる**」状態です。
pandas を網羅的に覚えることは目的にしていません。複雑な処理はAIに書かせる前提で、学習対象を3段階に分けています。

| 区分 | 意味 | 例 |
|---|---|---|
| **Write** | 何も見ずに5〜10秒で書けるようにする(問題演習の中心) | `df.isna().mean()`, `df[df["age"] >= 20]`, `df.groupby("cat")["val"].mean()` |
| **Read** | 読めればよい | named aggregation, `query()`, `pivot_table`, MultiIndex |
| **AI** | 必要になったらAIに書かせる | `apply()`, `transform()`, `rolling()`, `resample()`, 正規表現での文字列処理 |

同じことをする方法が複数ある場合、Write では基本形を1つだけ使います(一覧は [config/curriculum.yaml](config/curriculum.yaml) の `basic_form`)。

## 環境構築

[uv](https://docs.astral.sh/uv/) を使います(未インストールなら `pip install uv` または公式の手順で)。

```bash
cd pandas-practice
uv sync
```

Python 3.12 と pandas 3 などが `.venv/` に入り、`src` がパッケージとしてインストールされます。

## Notebook の起動

```bash
uv run jupyter lab
```

ブラウザで JupyterLab が開くので、`problems/P001/exercise.ipynb` から始めます。

VS Code で開く場合は、Notebook 右上のカーネル選択で `.venv`(`pandas-practice/.venv/Scripts/python.exe`)を選んでください。

## 問題の解き方

各問題のフォルダ `problems/Pxxx/` の **`exercise.ipynb`** を開き、上から順に実行します。

1. タイトル・目的・問題文を読む
2. 読み込みセルを実行する(データは `data/` に入っています)
3. **`solve` 関数の中を書く**

   ```python
   def solve(df: pd.DataFrame):
       return df.isna().sum()
   ```

4. `solve(df)` のセルで、実データでの結果を確認する
5. 採点セルを実行する
6. 感想を一言書いて保存する

詰まったら、別のセルで `hint("P015")` を実行するとヒントが1つずつ表示されます(使ったことは履歴に残ります)。

**探索(exploration)問題**には `solve` がありません。問題文の「答えられるようにしたいこと」を、自由にセルを追加して調べます。
終わったら `done("P006")` のセルを実行して記録し、`solution.ipynb` の確認項目と見比べます。

## 自動採点

```python
check("P015", solve)
```

- 小さな手計算できるデータ(基本ケース・境界ケース)で `solve` を実行し、期待される出力と比べます
- 失敗すると、最初に失敗したケースの**入力・期待される出力・あなたの出力**が表示されます
- 結果は `review/history.csv` に自動で記録されます。直近5分以内に同じ結果を記録済みなら記録しません(採点セルを何度実行しても大丈夫です)

## 感想の保存

各 Notebook の最後のセルで、`memo` の文字列だけを書き換えて実行します。

```python
memo = "groupbyの書き方がまだ曖昧"

save_review("P023", memo)
```

```text
Saved review: P023
```

- 一言で十分です(「ilocの列指定忘れた」「isnaのあとmeanで割合になるの便利」「余裕」など)
- 複数行で書きたいときは `memo = """ ... """`
- 空のままなら保存されません。同じ内容を5分以内に保存し直しても重複しません
- 保存先は `review/notes.yaml` です(直接編集する必要はありません)。同じ問題を何度解いても履歴として追記されます

## 解答の確認

同じフォルダの **`solution.ipynb`** を開きます。

1. シンプルな模範解答
2. コードの説明
3. 今回覚えるポイント
4. よくある間違い

の順に書いてあります。探索問題では、推奨確認項目・模範的なコード・このデータで観察すべきポイントが書いてあります。
問題を解く前に開かないようにしてください。

## 復習問題を Claude Code に頼む

このフォルダで Claude Code を起動し、普通に頼むだけです。Claude Code は `CLAUDE.md` のルールに従い、
`review/history.csv`(正誤)と `review/notes.yaml`(感想)、各問題の `metadata.yaml`(タグ)を読んで問題を選びます。

依頼の例:

- 「苦手なタグを中心に復習問題を5問作って」
- 「間違えた問題をもう一度解き直したい」 → 既存の問題に、解き直し用の空の Notebook(`exercise_retry_日付.ipynb`)が作られます
- 「groupby を中心に類題を3問作って」 → タグ指定の類題が新しい問題(P048〜)として追加されます
- 「今までの操作を組み合わせた EDA 問題を2問作って」 → 複合EDA問題

感想に「曖昧」「わからなかった」「復習したい」などと書いておくと、その問題が優先されます。

## トラブルシューティング

- **`ModuleNotFoundError: No module named 'src'`**: Notebook のカーネルが `.venv` になっていません。`uv run jupyter lab` で起動するか、VS Code でカーネルに `.venv` を選んでください
- **解答欄を消してしまった**: `uv run python tools/build_problems.py --retry P012` で空の Notebook を追加で作れます(元の Notebook は残ります)
- **全体の動作確認**: `uv run python tools/validate.py`(Notebook を実際に全部実行する場合は `--execute`)
